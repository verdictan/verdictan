# Security policy

## Supported versions

| Version | Supported |
| --- | --- |
| Latest 0.x release | Yes |
| Older 0.x releases | Best effort |

## Reporting a vulnerability

Email security@verdictan.com with:

- A description of the issue
- Steps to reproduce
- Impact assessment
- Affected versions

Do not open a public issue for an unpatched security vulnerability.

We aim to acknowledge reports within three business days.

## Scope

This policy covers the `verdictan` binary, the gateway runtime, and release
artifacts published from this repository.
